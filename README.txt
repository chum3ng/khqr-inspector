KHQR Inspector
==============
Open index.html in a browser, or upload this whole folder to GitHub Pages / any static host.
Keep the folder structure: index.html, styles.css, app.js and the vendor/ folder.

Third-party libraries (bundled in vendor/, no network needed):
- AngularJS 1.8.3 (MIT)
- qrcode-generator (MIT)
- jsQR 1.4.0 (Apache-2.0)

Notes
- Live camera scanning needs https:// or localhost. "Scan photo" works from a local file too.
- Image copy (QR "Copy" button) also needs https:// or localhost.
